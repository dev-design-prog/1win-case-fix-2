# Что изменилось

## Кейсы и NFT-подарки
- Меню «Кейсы» — отдельная вкладка, не смешана с играми. Шансы и цены — в `bot/cases_config.py`.
- Проверка окупаемости: `python bot/cases_config.py`.
- Результат кейса решает сервер (`/api/cases/open`), списание/приз/история — одной транзакцией.
- Профиль: вкладки «NFT-подарки», «Вывод ★», «Промокод». Подарок можно продать (цены из ТЗ) или вывести — заявка приходит всем админам с кнопками «Выдал / Отклонить». Отказ возвращает подарок в профиль.
- Вывод подарка требует те же условия, что и вывод звёзд (депозит от 1000★ + 1 час, либо админ-разблокировка).

## Upgrade
- Стрелка теперь крутится только вперёд и останавливается точно на ролле сервера. Раньше её каждый раз сбрасывали в 0 через CSS-transition — отсюда «один раз нормально, потом на миллиметр».
- Шансы на экране брались из старой таблицы (30/20/15/7/5%), а сервер считал по другой (50/35/25/15/10%). Теперь экран берёт шансы с сервера.

## Админ-панель (бот, /admin)
- 📊 Статистика: игроки, деньги, выводы, игры, кейсы, подарки.
- 🛠 Техработы: включить/выключить одной кнопкой. Админы и `MAINTENANCE_WHITELIST` заходят, остальные видят заслонку. Проверка и в мини-аппе, и на сервере (`/api/*` отвечает 503).

## Подписка на канал
- `/start` → «👋 Добро пожаловать! Подпишись на канал👇» → «Я подписался». Та же проверка стоит в мини-аппе и на сервере. Включается переменной `REQUIRED_CHANNEL`.

## Дизайн
- Новая палитра и шрифты, меню из 5 вкладок. Исходник интерфейса: `webapp/src/template.html`, сборка: `python webapp/src/build.py` → `webapp/index.html`.

## Фото в приветствии бота
- К сообщениям «Добро пожаловать! Подпишись на канал» и к главному приветствию прикрепляется фото `bot/assets/welcome.png` (замените файл — поменяется картинка). Текст — подпись к фото.
- После первой отправки бот запоминает file_id и больше не заливает файл. Нет файла или Telegram отклонил фото — уходит обычный текст.
- Для сообщений-фото `edit_text` теперь безопасно удаляет фото и присылает текстовое сообщение, поэтому кнопки меню работают как раньше.

## Загрузочный экран
- Анимация загрузки — Plush Pepe (`webapp/src/blobs/loading_tgs.txt` = `Plush_Pepe.tgs`). Чтобы поменять снова — подставить новый .tgs (base64) в этот блоб и запустить `python webapp/src/build.py`.

## Версия Python
- Добавлен `.python-version` (3.11.9): Render берёт версию Python из этого файла. Без него новые сервисы получают 3.14, на которой `psycopg2-binary==2.9.9` может не собраться.
- В `render.yaml` версия Python теперь задана переменной `PYTHON_VERSION=3.11.9` (документированный способ, имеет приоритет над файлом).

## Сборка на Render (ошибка pydantic-core / maturin / Rust)
- Причина: Render брал Python 3.14, а старые пины (aiogram 3.13.1, pydantic 2.9.2, aiohttp 3.10.10, psycopg2-binary 2.9.9) не имеют готовых сборок под 3.13+ и пытались компилироваться.
- `requirements.txt` переписан на диапазоны версий (aiogram 3.31+, aiohttp 3.13+, psycopg2-binary 2.9.11+): ставится из готовых сборок на Python 3.11, 3.12, 3.13 и 3.14. Версия Python на хостинге больше не критична.
- `/` и `/health` в API теперь async-обработчики (убрано предупреждение aiohttp).
